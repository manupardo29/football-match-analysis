# Football Match Analysis

Proyecto de Football Analytics desarrollado como parte de mi aprendizaje de analisis de datos aplicado al futbol.

## Objetivo

Analizar un partido real utilizando Python y datos de eventos para obtener estadisticas, visualizaciones y conclusiones sobre el rendimiento de equipos y jugadores.

## Tecnologias

- Python
- Pandas
- Matplotlib
- mplsoccer
- Jupyter Notebook
- Git / GitHub
